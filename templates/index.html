RNAdex

RNAdex contains 462,755 structural motif entries from 5,846 PDB structures — enabling researchers to search, visualize, and download atomic-level RNA structures.

Code Paper User Guide Database

RNAdex is a comprehensive 3D RNA motif library that extracts and catalogs RNA structural motifs from the Protein Data Bank using graph-based algorithms. It provides researchers with tools for type-based search, custom graph-based structural search via subgraph isomorphism, and atomic-level 3D coordinate downloads for accurate RNA structural analysis.
